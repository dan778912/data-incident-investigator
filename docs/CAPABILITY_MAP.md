## Definitive release evidence

The provider-matched NVIDIA release (`nvidia/nemotron-3.5-lightning-30b-a3b`,
corpus `1.0.0`) completed **19/20 strict workflows** and produced **20/20 exact
cause sets**. It recovered 57/63 required evidence facts, 22/22 required
sources, and 50/50 supported citations. All 20 originals were preserved; all
12 applied repairs passed postconditions; approval enforcement, replay
idempotency, and patch-policy compliance were 100%. The matching adversarial
suite proved **4/4 attacks blocked** with a 0/4 attack-success rate. Median
latency was 8.163 seconds and configured estimated model cost was $0.

I18 is the single strict workflow failure: the diagnosis is exact, but the
system safely refuses `drop_duplicates(keep="last")` because evidence does not
prove that physical input order matches greatest `event_version` and
`updated_at`. The definitive run also records zero revision successes and zero
second-round retrieval gain; those optional paths exist and are covered by
integration tests, but were not elicited by this model/run.

The current backend suite collects 214 tests. Focused release regressions cover
the NVIDIA adapter, bounded query policy, artifact-coverage retrieval,
unavailable-reference handling, all taxonomy dominance rules, numeric repair
synthesis, exact datetime-plan replacement, adversarial fail-closed
classification, and evidence freezing.

The map intentionally distinguishes code-enforced controls from prompt guidance
and does not claim multi-node durability or a free production model deployment.
